# App Store Radar v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a continuous App Store opportunity-research loop with full China paid-chart review coverage, daily/weekly readable evidence, scheduled ChatGPT research, and an ios-native-design product gate.

**Architecture:** Immutable Apple evidence remains in daily partitions. Deterministic Node.js code derives health checks, review signals, daily/weekly baselines, while scheduled ChatGPT runs perform current external validation and create/update actionable GitHub issues.

**Tech Stack:** Node.js 22, GitHub Actions, Apple public Search/Lookup/RSS/Marketing Tools endpoints, ChatGPT scheduled tasks, GitHub Issues.

**Spec:** `docs/superpowers/specs/2026-09-17-radar-v2-design.md`

## Global Constraints

- Raw `data/YYYY/MM/DD` partitions remain immutable.
- China `top-paid` review watchlist attempts all 100 ranked apps before lower-priority sampling.
- Missing chart positions are explicit health failures, never interpreted as no demand.
- Machine BUILD is provisional until external validation and counter-evidence checks complete.
- Final iOS BUILD issues must use the `ios-native-design` workflow and Design DoD.
